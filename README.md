# Hotel PMS Migration Checklist

Moving from one hotel PMS to another (or from register/Excel to your first PMS)? This checklist covers the full switch — built from real Indian hotel migrations.

## Phase 1 — Before you sign (with the new vendor)

- [ ] Export test: get YOUR data out of the current system and open it cleanly
- [ ] Confirm GST history migrates (folios, B2B invoices with GSTIN)
- [ ] Get onboarding scope in writing (who enters data, how long)
- [ ] Check contract exit terms on the old system (notice period, auto-renewal)

## Phase 2 — Parallel running (2–4 weeks)

- [ ] New PMS handles all live bookings from day one
- [ ] Old system stays readable for history lookups
- [ ] Never do a hard cutover on a Friday

## Phase 3 — People

- [ ] Front desk first (they touch it 100x/day), then housekeeping, then accounts
- [ ] One role per week — not everyone on day one
- [ ] Night audit: confirm who closes the day and how long it takes

## Phase 4 — Rates & OTAs

- [ ] Migrate seasonal rate plans manually (imports garble them)
- [ ] Reconnect each OTA channel one by one; verify availability sync
- [ ] Run one full billing day and reconcile against Tally
